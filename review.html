Галерея графиков — отзыв

Двадцать шесть типов графиков для отчётов по опросам и поведенческим данным: что двигает показатель и какие атрибуты важны, как делятся сегменты по правилам, кто что делает во времени, куда перетекают люди, где теряются заходы. Все графики нарисованы одной маленькой библиотекой поверх Apache ECharts, без сборки.

Под каждым графиком — три кнопки: Нравится, Не нравится, Доработать. У «Доработать» открывается поле для текста; к любой оценке можно добавить комментарий. Оценки сохраняются в браузере; внизу страницы — кнопка, которая собирает всё в один текст: скопируйте его в чат или отправьте как issue на GitHub.

Все цифры на странице — синтетические данные в трёх выдуманных сюжетах: сайт бронирования поездок, опрос гостей отелей и приложение для изучения языков.

Таймлайн состояний

ChartKit.stateTimeline

Когда: нужно объяснить, что значит сегмент. Одна маленькая панель на сегмент, в каждой — столбик до 100% на каждую отметку времени, цвет = где человек в этот момент. Панели отсортированы по показателю (здесь — доля бронирования), в подзаголовке показатель и размер сегмента. Правило: перед любой разбивкой по сегментам, найденным моделью, сначала показываем такой график — «на чём построены сегменты».

Код
ChartKit.stateTimeline('c-timeline', {
  segments: [{ name: 'Searches by dates first', share: 25, value: 39 }, ...],   // value = показатель, необязателен
  marks: [0, 10, 20, ..., 120], states: ['home', 'search form', ...],
  data: { 'Searches by dates first': { home: [100, 38, ...], 'search form': [0, 54, ...] }, ... },  // % на отметку, в сумме 100
  colors: { home: '#0F172A', ... }, base: 27, valueLabel: 'booking rate', shareLabel: 'of visits'
});

Стопка состояний

ChartKit.stateStack

Когда: нужно показать, где находятся все в каждый момент: площадь до 100%, слой = состояние, база — те, кто ещё на сайте. Тонкие слои в стопке не читаются, поэтому клик по слою или по кнопке-названию показывает состояние отдельно, от нулевой оси, со своими цифрами; клик по графику возвращает все слои. Отметки с маленькой базой приглушены. Шкала времени логарифмическая: видны и первые секунды, и хвост.

Код
const stack = ChartKit.stateStack('c-stack', {
  labels: ['0', '1 s', '2 s', ..., '30 min'], states: ['home', 'search form', ...],          // снизу вверх
  data: { home: [100, 99, ...], 'search form': [0, 1, ...], ... },                      // % на отметку; normalize: true досчитывает до 100
  colors: { home: '#334155', ... },
  base: [5000, 4980, ...], minBase: 700, lowBaseLabel: 'small base', baseLabel: 'sessions still going on:'
});
stack.isolate('search form');   // то же, что клик по слою; stack.isolate(null) — назад

Полоски отдельных заходов

ChartKit.sequenceIndex

Когда: рядом с агрегатом нужно показать отдельные пути, которые за ним стоят: каждая тонкая полоска — один заход от начала до конца, цвет = состояние в этот момент. Полоски сгруппированы по исходу (без бронирования / с бронированием) и отсортированы по длительности, красная отметка — ключевое событие (бронирование). Наведите мышь на полоску, чтобы увидеть детали.

Код
const seq = ChartKit.sequenceIndex('c-sequence', {
  rows: [{ group: 'booked', end: 271, mark: 240, segments: [[0, 33, 0], [33, 60, 1], ...] }, ...],   // [от, до, индекс состояния], секунды
  states: ['home', 'search form', ...], colors: { home: '#334155', ... },
  groups: [{ key: 'no booking', label: 'did not book' }, { key: 'booked', label: 'booked' }],
  markLabel: 'booking', scale: 'log'
});
seq.redraw({ scale: 'linear', maxTime: 600 });

Дерево сегментов

ChartKit.segmentTree

Когда: сегменты заданы правилами (дерево решений на переменных, которые двигают показатель). Каждое условие написано один раз, на своей развилке; в каждом узле, включая промежуточные, — доля базы и значение показателя. Размер кружка = доля, цвет = выше (синий) или ниже (оранжевый) среднего. Конечные сегменты справа. Правило: сегменты по правилам рисуем деревом, а не столбиками с длинными подписями-перечислениями.

Код
ChartKit.segmentTree('c-tree', {
  tree: { name: 'All visits', share: 100, value: 27, children: [
    { name: 'Came from a price alert', share: 5, value: 61 },
    { name: 'Booked here before', share: 24, value: 41, children: [...] } ] },
  base: 27, valueLabel: 'booking rate', shareLabel: 'of visits'
});
// python/tree_segments.py строит такую структуру из дерева sklearn

Драйверы: что двигает показатель

ChartKit.divergingBars

Когда: первый график темы или шага — что двигает показатель вверх и что вниз. Столбик = разница показателя «признак есть / нет» в процентных пунктах; в подписи оба значения и размер группы.

Код
ChartKit.divergingBars('c-drivers', {
  items: [{ name: 'Booked here before', withValue: 41, withoutValue: 23, share: 24 }, ...]
});

Пары столбиков

ChartKit.groupedBars

Когда: нужно сравнить две-три цифры по каждой категории, например долю заходов и долю бронирования у сегмента. Правило: то, что сравнивают, стоит рядом на одной шкале, а не в разных панелях.

Код
ChartKit.groupedBars('c-grouped', {
  names: ['Searches by dates first', ...],
  series: [{ name: 'share of visits', values: [...] }, { name: 'booking rate', values: [...] }]
});

Поток между группировками

ChartKit.flowSankey

Когда: нужно связать три группировки: с чего заход начался, что в нём происходило, чем кончился. Узлы переставлены так, чтобы меньше пересечений; похожие узлы в разных колонках одного семейства цветов; клик по узлу может вести в раздел отчёта про этот сегмент.

Кликните по узлу.

Код
ChartKit.flowSankey('c-flow', {
  columns: [['Searches by dates first', ...], ['compared in the results list', ...], ['Decisive booker', ...]],
  links: [{ source: 'Searches by dates first', target: 'compared in the results list', value: 661 }, ...],
  colors: { 'Searches by dates first': '#2563EB', ... }, pinLast: ['Saved nothing'],
  onNodeClick: name => location.hash = '#' + slug(name)
});

Карта сегментов

ChartKit.segmentMap

Когда: все сегменты надо показать на одной картинке: по горизонтали размер, по вертикали показатель. Подписи расставляются автоматически без наложений; если подпись пришлось отодвинуть, к точке идёт линия-выноска.

Код
ChartKit.segmentMap('c-map', {
  points: [{ name: 'Searches by dates first', x: 25, y: 39, group: 'first two minutes', color: '#2563EB' }, ...],
  xName: 'share of all visits, %', yName: 'booking rate, %',
  reference: { y: 27, label: 'average 27%' }
});

Лесенка

ChartKit.ladder

Когда: нужен стержень отчёта: «из 100 начавших до каждого шага дошло N», рядом с каждой ступенькой — потеря и её причина. Ступеньки могут быть ссылками на разделы, где шаг разобран.

Код
ChartKit.ladder('c-ladder', { steps: [
  { name: 'Opened the site', value: 100 },
  { name: 'Ran a search', value: 64, loss: 'left from the home page', href: '#step-1' }, ... ] });

Тепловая таблица

ChartKit.heatTable

Когда: сегменты описываются переменными. Ячейка закрашена только там, где значение заметно отличается от общего (не меньше 3 пунктов и 15% относительно), поэтому глаз идёт к настоящим различиям, а не к шуму.

Код
ChartKit.heatTable('c-heat', {
  rows: ['Booked here before', ...], columns: [{ name: 'Goes straight to booking', sub: '6% of visits' }, ...],
  values: { 'Booked here before': [52, 61, ...] }, overall: { 'Booked here before': 24 }
});

Карта «штраф – награда»

ChartKit.penaltyRewardMap

Показывает, что атрибут делает с выбором с двух сторон: x = штраф (насколько плохо исполненный атрибут отталкивает, в п.п.), y = награда (насколько хорошо исполненный притягивает). Пунктирные линии по средним делят поле на четыре зоны — привлекают (награда выше, штраф ниже), ключевые (обе выше), базовые (штраф выше, награда ниже), второстепенные; цвет точки = зона. Опция ci рисует крест доверительного интервала за точкой; подписи разводятся автоматически с выносками; под графиком — таблица зон. Вызов функции несколько раз с highlight и compact даёт малые множители по группам в общем масштабе.

Код
ChartKit.penaltyRewardMap('c-penalty-reward-map', {
  points: [{ name: 'Value for money', x: 8.5, y: 12.4, xCi: 2.3, yCi: 1.3 }, ...],   // x = penalty, y = reward, pp; ± optional
  xName: 'penalty, pp', yName: 'reward, pp', unit: 'pp',
  zones: { topLeft: 'attract', topRight: 'key', bottomRight: 'basic', bottomLeft: 'secondary' },
  ci: true, table: true                       // table: an element / id, or true = a div right after the chart
});
// small multiples: the same call per group with compact: true, highlight: 'Pool or gym', xRange: [-1, 17], yRange: [-1, 16]

Водопад вкладов

ChartKit.contributionWaterfall

Объясняет разрыв: как группа приходит от опорного значения (средний отель) к своему, по одному горизонтальному шагу на фактор. Шаги отсортированы по модулю, синий поднимает значение, оранжевый опускает; пунктирный столбик — сумма всех факторов, серый — остаток, который факторы не объясняют. Начальный и конечный столбики стоят от нуля, каждый шаг начинается там, где кончился предыдущий (прозрачный базовый стек). При наведении — значение и ± погрешность.

Код
ChartKit.contributionWaterfall('c-contribution-waterfall', {
  start: { label: 'Average hotel', value: 54.0 }, end: { label: 'Hotel D, actual', value: 62.1 },
  steps: [{ name: 'Location', value: 3.8, ci: 1.0 }, { name: 'Noise insulation', value: -2.2, ci: 0.9 }, ...],   // pp, sorted by |value|
  unit: '%', stepUnit: 'pp', summaryLabel: 'All attributes together', residualLabel: 'Not explained by attributes'
});

Столбики с точками

ChartKit.barWithDots

Когда одно число на пункт надо показать вместе с его устойчивостью: столбик — эффект на полной базе (синий поднимает исход, оранжевый опускает; один цвет, если мера без знака), точки — та же мера по волнам, от светлой к тёмной. С ci: true поперёк столбика рисуется ус доверительного интервала; в подсказке он есть всегда. Пункты отсортированы по модулю эффекта, самый большой сверху.

Код
ChartKit.barWithDots('c-bar-with-dots', {
  items: [{ name: 'Room cleanliness', value: 8.7, ci: 1.18, waves: [8.5, 8.2, 8.5] }, ...],   // value on the full base, one entry per wave
  waveNames: ['wave 1', 'wave 2', 'wave 3'], unit: ' pp', signed: true, ci: true, baseLabel: 'all waves'
});
// an unsigned score from an older method: { ..., signed: false, reference: '#7C3AED', unit: '%' }

Места по волнам

ChartKit.rankBump

Показывает, держится ли порядок пунктов от волны к волне: y = место (1 сверху), по линии на пункт через волны. Линии, сдвинувшиеся на minMove мест и больше (по умолчанию 5) между любыми двумя волнами, окрашены, остальные серые — взгляд идёт на настоящее движение; в конечной подписи чистый сдвиг, например «Breakfast quality (−7)». Наведение выделяет линию и показывает все места.

Код
ChartKit.rankBump('c-rank-bump', {
  waves: ['wave 1', 'wave 2', 'wave 3'],
  items: [{ name: 'Room cleanliness', values: [14.3, 15.56, 16.47] }, ...],   // or ranks: [1, 1, 2] directly
  minMove: 5, color: '#7C3AED'
});

Гантели

ChartKit.dumbbell

Используйте, когда в каждой строке нужно сравнить два значения одной меры — до и после, в первом поиске и в последнем, пользователи и непользователи. Две точки — значения, толстая линия между ними окрашена по направлению (синяя — второе значение выше, оранжевая — ниже), подписи на концах дают числа, короткий вертикальный штрих — база (общее значение) для строки или для всего графика. Строки, где разница незначима, передаются с dim: true и рисуются блёкло. Наведите на строку — увидите оба значения, разницу и базу.

Код
ChartKit.dumbbell('c-dumbbell', {
  rows: [{ name: 'Price range', a: 52, b: 38, reference: 44 }, { name: 'Pool', a: 11, b: 10, reference: 10, dim: true }, ...],
  aLabel: 'in the first search', bLabel: 'in the last search before booking', referenceLabel: 'in all searches',
  format: v => Math.round(v) + '%', min: 0            // reference: 44 (one base for all rows) or [refA, refB] per row
});

Лес коэффициентов

ChartKit.forestPlot

Используйте, чтобы показать, что по модели делает каждый фактор сам по себе при прочих равных: строка на коэффициент, точка — оценка, усы — 95% интервал, сортировка так, что самый большой эффект сверху. Опорная линия — 0 для разниц в процентных пунктах или 1 для отношений (scale: 'ratio', множители на логарифмической оси). Значимые строки (p ниже alpha или интервал не задевает опору) получают цветную точку — синюю выше опоры, оранжевую ниже, — тёмные усы и жирную подпись вида «+3.2 pp [1.1; 5.3]»; остальные серые. Наведите на строку — увидите числа и p-значение.

Код
ChartKit.forestPlot('c-forest-plot', {
  rows: [{ name: 'Studies daily', est: 21.3, lo: 15.6, hi: 27.0 }, { name: 'Aged under 35', est: -1.1, lo: -4.6, hi: 2.4, p: 0.54 }, ...],
  unit: 'pp', xName: 'change in the chance of finishing the course, pp'
});
ChartKit.forestPlot('c-forest-plot-ratio', { rows: [{ name, est: 1.71, lo: 1.38, hi: 2.12 }, ...], scale: 'ratio', nsLabel: '(n.s.)' });

Тепловая карта с кластерами

ChartKit.clusteredHeatmap

Используйте, чтобы увидеть, какие группы похожи друг на друга по профилю из многих переменных — типы отелей по тому, что ценят их гости, сегменты по поведению. Строки — переменные, столбцы — группы; ячейка закрашена по тому, насколько группа отличается от общего значения строки (синий — выше, оранжевый — ниже, насыщеннее — сильнее), или по самому знаковому значению, если общее не передано. Строки и столбцы переупорядочены кластеризацией Уорда, дендрограммы нарисованы рядом с картой (строки — справа, столбцы — снизу), так что похожие группы стоят рядом. С orderBy: 'City hotel' столбцы вместо этого сортируются по евклидову расстоянию до указанного столбца, расстояние пишется в заголовке, а дерево столбцов не рисуется. Наведите на ячейку — увидите значение и общее.

Код
ChartKit.clusteredHeatmap('c-clustered-heatmap', {
  rows: ['Room cleanliness', 'Value for money', ...], columns: ['City hotel', 'Resort', ...],
  values: [[71, 70, ...], [54, 49, ...], ...],      // one array per row, one number per column
  overall: [71, 58, ...],                            // cell = value − overall; omit to shade the signed values themselves
  cluster: { rows: true, cols: true }, unit: 'pp'    // or orderBy: 'City hotel' to sort columns by distance to one column
});

Сетевой граф

ChartKit.networkGraph

Используйте, чтобы показать построенную сеть бинарных поведений — байесовскую сеть, путевую модель — в стиле «Tetrad + Gephi»: узел — поведение, его размер — доля людей с этим поведением (6 + 34·sqrt(доля / макс)), цвет — сообщество, найденное жадным проходом по модулярности (или переданное для узла), подпись — «Название N%». Ребро — коэффициент модели: толщина = 1 + 9·|coef| / макс, цвет — цвет узла-источника с прозрачностью 85%, изогнутое, со стрелкой, с подписью «.23». По умолчанию — детерминированная силовая раскладка Фрухтермана — Рейнгольда; с layout: 'columns' узлы ставятся в столбцы по node.column (вид «путь к цели»), внутри столбца упорядочены по барицентру предшественников, над столбцами подписи, целевой узел обведён кольцом, входящие в него рёбра нарисованы цветом текста. Наведите на узел или ребро — увидите числа; тяните — панорамирование, колесо — масштаб.

Код
ChartKit.networkGraph('c-network-graph', {
  nodes: [{ name: 'Signed in', prevalence: 38, column: 0 }, { name: 'Compared rooms', prevalence: 17, column: 2 }, { name: 'Booked', prevalence: 27, column: 3 }, ...],
  edges: [{ source: 'Compared rooms', target: 'Booked', coef: 0.43 }, { source: 'Entered dates', target: 'Browsed destinations', coef: -0.22 }, ...],
  target: 'Booked', layout: 'force'                      // or layout: 'columns', columns: ['How the visit started', 'First actions', 'Engagement', 'Outcome']
});

Карта рисков

ChartKit.riskMap

Ранжирует то, что ломается по дороге к результату: x — как часто событие случается (доля заходов, логарифмическая шкала), y — как часто после него уходят без результата. Площадь кружка — потерянные заходы, цвет — шаг пути, полый кружок — мало случаев, усы — 95% интервал Уилсона, пунктир — фон после обычного действия. Курсивные подписи называют квадранты; заливка — «часто и хотя бы вдвое выше фона». Наведение показывает счётчики.

Код
ChartKit.riskMap('c-risk-map', {
  events: [{ name: 'no rooms for these dates', note: 'sold out', category: 'search', x: 6, n: 3600, k: 1440 }, ...],   // x = % of sessions, k = lost of n
  background: 9.5, backgroundLabel: 'background, ordinary action', minN: 100,                                   // hollow bubble below minN
  colors: { start: '#334155', search: '#2563EB', ... }, labelPositions: { 'page crash': 'right' },
  quadrants: { topLeft: 'rare but deadly', topRight: 'mass killers', bottomRight: 'loud but harmless', bottomLeft: 'almost harmless' },
  zone: { x: 5, factor: 2, label: 'common and deadly' }, xName: 'share of sessions (log) →', yName: '↑ lost within a minute, %'
});

Плотность событий во времени

ChartKit.eventDensity

Показывает, когда что-то происходит после ключевого момента (бронирование, регистрация): по одной сглаженной кривой на канал на логарифмической оси времени с читаемыми делениями (30 с, 1 мин, … 24 ч или дни, если деления переданы). Кривая — ядерная плотность логарифма времени с пиком 1, поэтому сравниваются формы, а не объёмы; подсказка даёт накопленную долю канала к моменту под курсором. Пунктирные вертикали — вехи («письмо-напоминание»). Можно передать сырые времена (плотность считается в браузере) или готовые кривые.

Код
ChartKit.eventDensity('c-event-density', {
  channels: [{ name: 'contact property (1250)', color: '#2563EB', times: [18, 6400, 2.5, ...] },      // minutes since the key moment

Бабочка состояний

ChartKit.stateButterfly

Когда «ушедшая» масса важна не меньше активной: 100%-стек по времени, зеркальный относительно нуля — состояния «вышел» и «пауза» растут вверх, активные экраны лежат под линией, ось y идёт 0–100 в обе стороны. Отметки времени (лог или линейные) задаются подписями. Клик по элементу легенды выключает состояние; наведение даёт точные доли в отметке.

Код
ChartKit.stateButterfly('c-state-butterfly', {
  labels: ['0', '1 s', '2 s', ..., '2 h'], states: ['home', 'search form', ..., 'paused', 'left without booking', 'left with booking'],
  up: ['paused', 'left without booking', 'left with booking'],                 // drawn above zero; the rest below
  data: { home: [100, 99, ...], 'left with booking': [0, 0, ...], ... },         // % of ALL sessions per mark
  colors: { home: '#334155', ... }, yName: '← active on the site        left or paused →'
});

Панель сегментации

ChartKit.segmentationPanel

Первая таблица после сегментации: строка на сегмент — имя, полоска доли базы, полоска результата со значением и спарклайн таймлайна состояний: крошечный 100%-столбик на отметку времени, цвет — состояние. Строки отсортированы по результату, общая строка сверху — глаз за один проход читает «кто большой, кто конвертируется, что они делают». Наведение на столбик спарклайна показывает долю состояния. Анатомия захода

ChartKit.sessionAnatomy

Покажите один заход как историю: общая ось времени (линейная или логарифмическая; паузы длиннее `pauseAfter` заштрихованы и укорочены), дорожки = экраны цветными отрезками с чёрточкой на каждом переходе, строка действий с выбором — что добавили в подборку или в поездку (нумерованная точка = новая позиция, маленькая точка = «ещё одна», красный крест = убрал), строка запросов (ромб в начале запроса, красный — если ничего не найдено, полоска — пока выдача была на экране), ромбики там, где открыта карточка, пунктирное окно подсветки, булавки событий и необязательная ступенчатая дорожка значения (баланс, сумма поездки) сверху. Подсказки — при наведении. Переключатели делает вызывающий: `redraw({ scale: 'log' })`, `redraw({ compressPauses: false })`.

Код
const s = ChartKit.sessionAnatomy('c-session-anatomy', {
  lanes: ['home', 'search form', 'results list', 'hotel page', 'room choice', 'booking form'],   // top to bottom
  segments: [[0, 11, 0], [11, 38, 1], [38, 97, 2], ...],                       // [from s, to s, lane index]
  end: 934, scale: 'linear', compressPauses: true, pauseAfter: 120,
  adds: [{ t: 221, n: 1, name: 'studio by the beach, 2 nights', note: 'from the room list' }, { t: 392, name: 'old town guesthouse' }],   // no n = one more of an item
  removes: [{ t: 790, name: 'studio by the beach, 2 nights' }], cards: [{ t: 99, name: 'guesthouse by the pier' }],
  queries: [{ t: 13, text: 'seaside town', found: 86, until: 97 }, { t: 232, text: 'old twon', found: 0 }],
  events: [{ t: 929, label: 'booked 211.00', color: '#059669' }], highlight: { from: 0, to: 120, label: 'first two minutes' },
  valueTrack: [{ t: 221, v: 234 }, ...], valueLabel: 'trip total',             // optional step line on top
  words: { items: 'stays in the trip', queries: 'destination searches', added: 'added stay', plusOne: 'one more night' }   // row captions and tooltip words
});
s.redraw({ scale: 'log' });   // s.redraw({ compressPauses: false }); s.dispose()

Граф переходов

ChartKit.transitionGraph

Покажите, куда уходят с каждого экрана. Узлы стоят там, где вы их поставили (фиксированная раскладка сохраняет картинку между группами), размер узла ~ корень из числа входов, подпись даёт входы, медиану пребывания и долю уходов, на которых заход кончается; направленные рёбра окрашены по источнику, ширина ~ корень из числа переходов, подпись — доля уходов из источника, рёбра тоньше `minShare` скрыты. Ссылки на цель, которой нет среди узлов, считаются выходами. `matrix: true` добавляет под графиком полную таблицу «откуда → куда» с синей заливкой; при `links2` и `matrixMode: 'diff'` таблица показывает разницу двух групп в п.п. (синее = больше в первой группе, оранжевое = меньше).

Код
const tg = ChartKit.transitionGraph('c-transition-graph', {
  nodes: [{ name: 'home', x: 80, y: 330, entries: 24000, dwell: 9, color: '#334155' }, { name: 'search form', x: 360, y: 110, entries: 17800, dwell: 24 }, ...],
  links: [{ source: 'home', target: 'search form', count: 9347 }, { source: 'booking form', target: 'left with booking', count: 1988 }, ...],  // unknown target = exit
  links2: [...same shape for a second group...], goodEnds: ['left with booking'],
  minShare: 15, matrix: true, matrixMode: 'links'   // 'links2' | 'diff' (links minus links2, pp)
});
tg.redraw({ links: BOOKED, minShare: 25 });   // chips / switches are the caller's job; tg.dispose()

Семантическая карта

ChartKit.semanticMap

Карта для исследования двумерного вложения (t-SNE, UMAP) текстов или объектов: точка = единица, цветная — если из одной из главных групп, серая — из другой группы, кольцо — без группы. Под главными группами лежит свечение. Масштаб колесом после клика по карте (или с Ctrl), перетаскивание, двойной клик или кнопки + / − / сброс. Подписи меняются с масштабом: названия групп и их главные слова при малом увеличении, подгруппы при среднем, мелкие скопления при большом; плашки подписей расходятся и указывают на центроид выноской. Наведение на точку или подпись — подсказка; чипы групп фокусируют одну группу (наведение — предпросмотр, клик — закрепить). `onClick(point, label)` получает точку или подпись, по которой кликнули.

Код
const map = ChartKit.semanticMap('c-semantic-map', {
  points: [{ x: -3.2, y: 1.7, group: 'price', sub: 'too expensive', cluster: 'too expensive / 1', text: '...' }, ...],   // group: null = unlabelled
  levels: [{ zoom: 1, field: 'group' }, { zoom: 2.2, field: 'sub' }, { zoom: 5, field: 'cluster' }],
  words: { group: { price: ['expensive', 'fee', 'deal'] }, sub: { 'too expensive': ['expensive', 'price', 'overpriced'] }, cluster: { ... } },
  maxGroups: 8, colors: { price: '#F97316' },      // top groups get colours, the rest are grey
  onClick: (point, label) => { ... }              // one of the two is set
});
map.focus('price'); map.reset(); map.redraw({ points: NEW }); map.dispose();

График покрытия

ChartKit.coverageChart

Покажите, какую часть базы покрывает набор элементов (тегов, правил, признаков) и где добавление новых перестаёт окупаться: столбец на элемент в жадном порядке, серое = уже покрыто предыдущими, синее = впервые покрыто этим, сверху «+N», ось y в процентах базы. Столбцы после последнего элемента, который добавляет хотя бы `minGain` базы, стоят за пунктиром — это плато. Передайте готовые `{ items, covered, added }` или сырые множества `sets: { item: [ids] }` — тогда жадный порядок считается здесь. `onClick(item)` срабатывает по столбцу или подписи.

Код
ChartKit.coverageChart('c-coverage-chart', {
  sets: { 'general praise': [1, 4, 9, ...], 'price': [4, 12, ...], ... },            // raw memberships: greedy order is computed here
  total: 1500, minGain: 0.005,                                                       // or precomputed: items: [...], covered: [483, 671, ...], added: [483, 188, ...]
  coveredLabel: 'already covered by earlier tags', addedLabel: 'newly covered by this tag',
  onClick: item => console.log(item)
});
ChartKit.greedyCoverage(sets, total)   // -> { items, covered, added, total } if you need the order alone
