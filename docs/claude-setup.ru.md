# Как рисовать эти графики с помощью Claude

Инструкция для того, кто получил ссылку на этот репозиторий и хочет, чтобы его Claude (Claude Code или
claude.ai) рисовал графики из галереи в отчётах.

## Что здесь лежит

| Что | Где |
|---|---|
| Галерея с примерами и кодом (английская) | `index.html` |
| Галерея с кнопками «Нравится / Не нравится / Доработать» (русская) | `review.html` |
| Библиотека графиков (`window.ChartKit`, поверх Apache ECharts 5) | `lib/charts.js`, `lib/charts.css` |
| Скилл для Claude: когда какой график, формат данных, правила подачи | `skills/chart-gallery/SKILL.md` |
| Одностраничная офлайн-версия галереи (ECharts встроен) | `dist/chart-gallery-single.html` |
| Помощники на Python (дерево сегментов, порядок узлов потока) | `python/` |

Все цифры в примерах синтетические.

## Шаг 1. Получить файлы

```bash
git clone https://github.com/Uwolfson/chart-gallery.git
```

Или на странице репозитория: Code → Download ZIP, распаковать. Открыть `review.html` двойным кликом —
страница работает с диска, сервер не нужен (ECharts грузится из интернета; без интернета откройте
`dist/chart-gallery-single.html`).

## Шаг 2. Подключить скилл к Claude Code

Скилл — это папка с файлом `SKILL.md`. Claude Code подхватывает скиллы из папки проекта или из личной папки.

Вариант А, для одного проекта (отчёта):

```bash
mkdir -p .claude/skills
cp -r chart-gallery/skills/chart-gallery .claude/skills/
cp -r chart-gallery/lib lib
```

Вариант Б, для всех проектов:

```bash
mkdir -p ~/.claude/skills
cp -r chart-gallery/skills/chart-gallery ~/.claude/skills/
```

(в Windows личная папка — `C:\Users\<имя>\.claude\skills\`).

После этого в Claude Code достаточно написать `/chart-gallery` или просто попросить: «нарисуй дерево
сегментов как в chart-gallery» — Claude прочитает скилл и возьмёт оттуда формат данных и правила.

## Шаг 3. Если Claude без доступа к файлам (claude.ai в браузере)

Приложите к разговору три файла: `skills/chart-gallery/SKILL.md`, `lib/charts.js`, `lib/charts.css`,
и напишите:

> Это библиотека графиков и инструкция к ней. Рисуй графики для отчёта только этими функциями,
> по правилам из SKILL.md. Данные подставляй мои.

## Что сказать Claude, чтобы получилось как в галерее

- Назовите тип графика словами из галереи: «таймлайн состояний», «стопка состояний», «полоски заходов»,
  «дерево сегментов», «драйверы (расходящиеся столбики)», «пары столбиков», «поток», «карта сегментов»,
  «лесенка», «тепловая таблица».
- Скажите, что показатель (например, доля бронирования) и что база (например, заходы на сайт).
- Дайте данные в виде таблицы или JSON; форматы для каждого графика описаны в SKILL.md, раздел 3.
- Попросите одну HTML-страницу, которая открывается с диска: Claude встроит графики через `ChartKit`.

## Как оставить отзыв о графиках

Откройте `review.html`, под каждым графиком нажмите «Нравится», «Не нравится» или «Доработать»
(откроется поле для текста). Внизу страницы кнопка «Скопировать отзыв» соберёт всё в один текст —
вставьте его в чат автору. Кнопка «Отправить как issue на GitHub» делает то же самое, но заводит issue в
этом репозитории (нужен доступ к нему).
